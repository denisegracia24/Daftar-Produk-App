# Daftar Produk App

Aplikasi desktop berbasis **JavaFX** dengan arsitektur **MVC (Model-View-Controller)** yang dirancang untuk memudahkan pengelolaan produk makanan dan minuman secara efisien.

## Fitur Utama

- **Auto-Increment Kode Produk**: Otomatis menghasilkan kode produk berurutan (M001, M002, dst.).
- **Pencarian Multi-Kriteria**: Mendukung pencarian berdasarkan Kode, Kategori, Nama Produk, dan Harga.
- **Manajemen Data**: Tambah, Lihat Detail, dan Hapus produk.
